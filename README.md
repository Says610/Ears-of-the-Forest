# Ears of the Forest

🍎 HUNGER SYSTEM - Must find and eat berries/mushrooms
💧 THIRST SYSTEM - Must collect water from streams
🌡️ BODY TEMPERATURE - Stay warm, avoid hypothermia
🔥 CAMPFIRES - Warm up at campfires
🍄 MUSHROOMS - Some edible, some poisonous (30% chance)
🥤 WATER COLLECTION - Drink from water sources
🏃 STAMINA IMPROVED - Exhaustion state when overused
🌧️ WEATHER SYSTEM - Rain affects temperature
📊 STATS TRACKING - Distance, items, encounters tracked
🎮 BETTER CONTROLS - E to interact, separate keys for actions

Quick Controls:
Click game → Activate mouse look
WASD → Move
Mouse → Look around
Shift → Sprint
C → Crouch
F → Toggle flashlight
H → Use medkit
B → Use battery
E → Interact/pick up items
M → Eat mushroom
N → Eat berries
R → Drink water
ESC → Pause/Skip

Survival Tips:
Keep hunger above 20%
Keep thirst above 20%
Stay near campfires when cold
Some mushrooms are poisonous!
Listen for wolf howls
Use flashlight sparingly
Follow the path to escape
